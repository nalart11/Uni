# Uni yo!!~

Uni is an open-source project written from scratch in C++ that will hopefully turn into a real programming language in the future.

## Why does it exist and what is it for?

Honestly, the main reasons I started making this thing were my motivation to learn C++, my interest in low-level programming, and my desire to create a simple low-level programming language that could be a good starting point for learning programming.

Btw, Uni is heavily inspired by Kotlin from JetBrains, which I really like.
